# 🍔 CampusBite Manager

**A Python-Based College Canteen Management System**

CampusBite Manager is a menu-driven Python project designed to simplify college canteen operations through student ordering and staff order management.

## 🚀 Features
- 🎓 Student registration and login using Student ID
- 🍽️ Food menu with prices
- 🛒 Multi-item ordering with quantity selection
- 💰 Automatic bill calculation and order receipts
- 🔍 Order tracking and order history
- 🛠️ Staff login and order management
- 🔄 Order status updates: Pending, Preparing, Ready, Completed
- 💾 Persistent storage using JSON files
- 🎨 Colorful terminal interface with emojis

## 🧰 Tech Stack
- **Language:** Python
- **Modules:** `json`, `os`
- **Storage:** JSON files
- **Interface:** Command-Line Interface (CLI)

## ⚙️ How to Run
1. Install Python 3.8 or later.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python canteengdg03.py
```

*Replace `canteengdg03.py` with your actual Python filename if different.*

## 📂 Project Files
- `canteengdg03.py` — Main application
- `orders.json` — Saved order records
- `students.json` — Registered student profiles
- `README.md` — Project documentation

The JSON files are created when data is saved for the first time.
